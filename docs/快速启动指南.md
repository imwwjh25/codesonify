# CodeSonify 快速启动指南

## 项目信息

- **名称**: CodeSonify - 代码复杂度声音化分析系统
- **版本**: 1.0.0-SNAPSHOT
- **技术栈**: Spring Boot 3.2.0 + Java 21
- **架构**: DDD 四层架构

---

## 快速启动

### 1. 环境要求

```bash
java -version  # 需要 Java 21+
mvn -version   # 需要 Maven 3.6+
```

### 2. 启动应用

```bash
cd /Users/Zhuanz/codesonify
mvn spring-boot:run
```

应用启动后访问：
- **前端页面**: http://localhost:8080/index.html
- **API 文档**: http://localhost:8080/swagger-ui.html

### 3. 测试 Demo

使用内置的示例项目进行测试：

```bash
# 分析示例项目
curl -X POST "http://localhost:8080/api/analysis/analyze?projectPath=/Users/Zhuanz/codesonify/demo-test/sample-project"

# 生成音乐（使用返回的 analysisId）
curl -X POST "http://localhost:8080/api/sonification/generate?analysisId=<analysisId>"
```

## 核心功能

### 代码分析

| 指标 | 说明 |
|------|------|
| 圈复杂度 | 代码逻辑复杂度，1-5 简单，6-10 中等，11+ 复杂 |
| 嵌套深度 | 代码嵌套层数 |
| 代码行数 | 方法代码行数 |
| 方法类型 | Getter/Setter/Constructor/业务方法 |

### 音乐生成

| 代码指标 | 音乐参数 | 效果 |
|----------|----------|------|
| 复杂度高 → 音高高 | 更尖锐的声音 |
| 嵌套深 → 音量大 | 更强的音量 |
| 代码长 → 时长长 | 更长的音符 |

### 下载音乐

1. 点击「生成音乐」按钮
2. 生成成功后点击「下载 MIDI 文件」
3. 使用本地播放器或上传到 [onlinesequencer.com](https://onlinesequencer.com/) 播放

## 常见问题

### Q: 为什么分析结果是 0？

**A**: 检查项目路径是否正确，确保路径下有 `.java` 文件。

### Q: 为什么音乐无法播放？

**A**: MIDI 文件需要使用专用播放器。推荐：
- 下载后用 VLC、Windows Media Player 播放
- 上传到 onlinesequencer.com 在线播放

### Q: 如何修改音乐风格？

**A**: 调整 `ComplexityToMusicMapper.java` 中的映射规则。

### Q: 可以分析其他语言吗？

**A**: 目前仅支持 Java。扩展其他语言需要添加对应的 Parser。

## 配置说明

### application.yml

```yaml
server:
  port: 8080

codesonify:
  analysis:
    cache-ttl: 3600        # 缓存时间（秒）
    max-file-size: 1048576 # 最大文件大小（字节）
  sonification:
    bpm: 120               # 音乐速度
    base-note: 60          # 基础音高
```

## 开发指南

### 添加新的分析指标

1. 在 `ComplexityMetrics.java` 添加字段
2. 在 `ClassAnalyzer.java` 添加计算逻辑
3. 在 `ComplexityToMusicMapper.java` 添加映射规则

### 修改音乐生成逻辑

编辑 `MidiGenerator.java`:

```java
// 修改乐器映射
int instrument = mapper.methodTypeToInstrument(metric.getMethodType());

// 修改音符生成逻辑
addNote(track, tickPosition, pitch, velocity, duration);
```

### 运行测试

```bash
mvn test
```
