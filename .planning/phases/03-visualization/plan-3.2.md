# Plan 3.2: 实现 HtmlReportGenerator HTML 报告生成器

**Wave**: 2  
**优先级**: P0  
**预计耗时**: 4 小时

---

## 目标

生成包含代码复杂度分析结果的 HTML 交互式报告。

## 任务

- [ ] 创建 `HtmlReportGenerator` 类
- [ ] 实现复杂度分布图表（使用 Chart.js）
- [ ] 实现类列表表格（支持排序）
- [ ] 嵌入 MIDI 播放器（播放代码音乐）
- [ ] 支持导出为 PDF

---

## 验收标准

1. HTML 报告可以在浏览器中正常显示
2. 图表正确展示复杂度分布
3. MIDI 播放器可以播放代码音乐
4. 页面美观、响应式布局
