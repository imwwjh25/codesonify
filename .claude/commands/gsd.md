# GSD 工作流技能

GSD (Get Shit Done) 工作流提供了一系列命令来帮助你高效地进行项目开发。

## 可用命令

输入 `/gsd:` 后跟以下命令：

### 项目初始化
- `/gsd:new-project` - 初始化新项目
- `/gsd:quick` - 快速任务（小修改）
- `/gsd:fast` - 快速执行

### Phase 执行
- `/gsd:execute-phase <N>` - 执行 Phase N
- `/gsd:discuss-phase <N>` - 讨论 Phase N
- `/gsd:plan-phase <N>` - 规划 Phase N
- `/gsd:ui-phase <N>` - 生成 UI 设计

### 工作管理
- `/gsd:add-todo` - 添加待办事项
- `/gsd:check-todos` - 检查待办事项
- `/gsd:progress` - 查看进度
- `/gsd:settings` - 查看/修改设置

### 高级命令
- `/gsd:autonomous` - 自主执行所有剩余 phases
- `/gsd:research-phase <N>` - 研究 Phase N
- `/gsd:validate-phase <N>` - 验证 Phase N
